Ampcus Helpdesk

Write better helpdesk prompts

Clear prompts get faster, cheaper answers. Vague ones waste tokens and create tickets. Use this short guide, then mark training complete.

Rubric (1–10)

  • Specificity (0–3) — name the system, policy, or error
  • Clarity (0–3) — one clear question
  • Context (0–2) — error text, when it started, what you tried
  • Actionability (0–2) — something an agent can answer or do

Examples

Weak: “VPN broken”

Strong: “VPN fails with error 809 after MFA on Windows 11 — I already reinstalled the client. How do I fix it?”

Weak: “PTO?”

Strong: “How many PTO days do I accrue per year as a full-time employee, and how do I request leave in Workday?”

Tips

  1. Lead with the goal (“How do I…”, “What is the policy for…”).
  2. Include product names, error codes, and screenshots descriptions.
  3. Say what you already tried so we don’t repeat steps.
  4. Ask one question per message when possible.
